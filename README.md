# Serene Bliss Villa 🌴

This is a premium, modern, and responsive website for a Luxury Villa in Sri Lanka. It features a sleek design, smooth animations, and a seamless booking flow.

## 🚀 Live Demo
[Click here to view the Live Site]https://hkmadusanka.github.io/luxury-villa-srilanka/

## ✨ Features
- **Responsive Design:** Works perfectly on Mobile, Tablet, and Desktop.
- **Minimalist Aesthetic:** Clean, elegant dark-mode design with gold accents.
- **Booking System:** Easy-to-use reservation form with local data handling.
- **Gallery & Highlights:** showcase villa features and customer experiences.

## 🛠️ Built With
- HTML5
- Tailwind CSS
- JavaScript
